# 示例语料（全部虚构）

这里是一个虚构的「家庭 NAS 迁移」项目的 6 篇文档，用来演示三件事：

1. **同一件事有新老两版结论**：`决策记录_2026-09-12.md` 选 RAIDZ1，`决策记录_2026-11-06.md` 改成单盘。
   问「现在用什么方案」，只按相似度会命中旧的那篇（写得更细），加上时间项才会翻过来。
2. **文件名带日期**：文件名里的 `2026-11-06` 就是块的日期。
3. **正文里的历史日期是陷阱**：`审计档案_2026-11-09.md` 正文写着 `2019-01-02`，
   取「第一个日期」会把整篇标成 2019 年、衰减算成 0；取「离 mtime 最近的日期」才对。
4. **完全没日期的文件**（`运维手册.md`）退回文件 mtime。

试一下：

```bash
python decay_rag.py build data/sample --index idx.json
python decay_rag.py query "现在用哪个 RAID 方案" --index idx.json
python decay_rag.py query "现在用哪个 RAID 方案" --index idx.json --no-decay
python decay_rag.py query "冷备盘轮换要多久做一次" --index idx.json --current-only
```

> 示例语料、数字、人名、项目名均为虚构，与仓库作者的真实资料无关。
